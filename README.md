## About

**ChatWebUI** is a lightweight, distraction-free AI chat interface built with pure HTML, CSS, and Vanilla JavaScript. Designed for instant loading, crisp Persian RTL and English LTR typography, and smooth token-by-token streaming with any Unicollect or OpenAI-compatible backend.

## Features

- **Zero-Bloat Pure Frontend** — No heavy frameworks or build steps; loads instantly in any modern browser or on GitHub Pages.
- **Bilingual Persian & English UI** — Native RTL/LTR layout with clean typography, code syntax highlighting, and Markdown/LaTeX math rendering.
- **Real-Time Streaming** — Smooth SSE token-by-token responses with stop-generation control and one-click copy buttons.
- **Multi-Mode Switcher** — Switch seamlessly between chat, reasoning, coding, and image generation modes from a single workspace.
- **Inline Image Display** — Renders generated images cleanly right inside the conversation stream.
- **Local Conversation History** — Keeps your chats and preferences private in your browser with zero external trackers or telemetry.

## Quick Start

1. Clone or download the repository:

```bash
git clone https://github.com/TernuxPJ/ChatWebUI.git
cd ChatWebUI
```

2. Open `index.html` in your browser (or serve it via any static host / GitHub Pages) and connect it to your Unicollect backend URL (such as [ChatWebUIGoogleColab](https://github.com/TernuxPJ/ChatWebUIGoogleColab)).
